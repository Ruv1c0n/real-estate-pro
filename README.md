# Real Estate Pro

Учебный микросервисный агрегатор объявлений о недвижимости с мгновенными уведомлениями.

Сервис собирает объявления об аренде и продаже квартир с разных площадок и из разных стран, приводит их к единому формату и отдаёт через единый поиск с фильтрами. Пользователь может сохранить поиск (например, «1-к в Минске до $400») и получить уведомление в Telegram, как только появится подходящее объявление.

## Стек

- **Backend:** Python (FastAPI) и Go
- **База данных:** PostgreSQL (своя схема на каждый сервис), миграции Alembic
- **Кэш, дедупликация, события:** Redis (кэш, множества хэшей, Pub/Sub)
- **Сбор данных:** httpx, BeautifulSoup
- **Фронтенд:** HTML, Jinja2, HTMX
- **Уведомления:** Telegram Bot API
- **Запуск:** Docker, docker-compose

## Сервисы

| Сервис      | Порт | За что отвечает                                                        | Папка        |
|-------------|------|------------------------------------------------------------------------|--------------|
| `core-api`  | 8000 | Хранилище объявлений, поиск с фильтрами и пагинацией, кэш, события     | `core-api/`  |
| `collector` | 8001 | Адаптеры источников, нормализация, mock-режим, веб-интерфейс           | `collector/` |
| `notifier`  | 8080 | Пользователи, сохранённые поиски, Telegram-бот, рассылка уведомлений   | `notifier/`  |
| `postgres`  | 5432 | Хранилище данных (схемы `core` и `notifier`)                           |              |
| `redis`     | 6379 | Кэш, дедупликация, канал `listings.new`                                |              |

## Как это работает

```
collector ──POST /api/v1/listings──▶ core-api ──▶ PostgreSQL
                                        │
                                        └─ PUBLISH listings.new ─▶ Redis ─▶ notifier ─▶ Telegram
```

1. `collector` забирает объявления из источников, нормализует и отправляет в `core-api`.
2. `core-api` сохраняет новое объявление, сбрасывает кэш списков и публикует событие в Redis.
3. `notifier` получает событие, сверяет его с подписками пользователей и отправляет уведомление.

## Запуск

Нужен установленный и запущенный [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
git clone <адрес репозитория>
cd real-estate-pro
cp .env.example .env     # на Windows: copy .env.example .env
docker compose up --build
```

После запуска откройте:

- веб-интерфейс — http://localhost:8001

Остановить: `Ctrl+C`, затем `docker compose down`. Чтобы удалить и данные БД: `docker compose down -v`.

## Настройка (.env)

| Переменная           | Назначение                                                              |
|----------------------|-------------------------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather. Если пуст, notifier пишет совпадения в лог   |
| `MOCK_MODE`          | `true` — collector берёт данные из локальных JSON-дампов               |

Остальные параметры (адреса БД и Redis) заданы в `docker-compose.yml`.

## Mock-режим

Реальные площадки могут блокировать автоматический сбор данных (капча, блокировка по IP). Поэтому collector умеет работать на локальных JSON-дампах (500+ объявлений из разных стран). Дампы имеют тот же формат, что и ответ реального адаптера, поэтому остальная система не отличает mock от реального источника. При ошибке реального источника collector переключается на mock автоматически.

## API

| Метод и путь                    | Описание                                             |
|---------------------------------|------------------------------------------------------|
| `GET /api/v1/listings`          | Список с фильтрами и пагинацией                      |
| `GET /api/v1/listings/{id}`     | Карточка объявления                                  |
| `POST /api/v1/listings`         | Сохранение объявления (вызывается collector)         |
| `GET /api/v1/cities`            | Справочник городов (также `countries`, `sources`, `currencies`) |
| `GET /health`                   | Состояние сервиса                                    |

Фильтры `GET /api/v1/listings`: `deal_type` (`rent`/`sale`), `country`, `city`, `price_min`, `price_max` (в USD), `rooms`, `area_min`, `area_max`, `source`, `sort`, `page`, `size`.

### Событие `listings.new` (Redis Pub/Sub)

Формат сообщения, по которому общаются `core-api` и `notifier`. Менять поля можно только по согласованию с командой.

```json
{
  "id": 123,
  "deal_type": "rent",
  "country": "BY",
  "city": "Минск",
  "rooms": 1,
  "price": 380,
  "currency": "USD",
  "price_usd": 380,
  "area_m2": 38.5,
  "address": "ул. Примерная, 1",
  "url": "https://example.com/listing/123",
  "source": "mock",
  "created_at": "2026-10-09T12:00:00Z"
}
```

## Команды Telegram-бота

| Команда            | Действие                                  |
|--------------------|-------------------------------------------|
| `/start`           | Регистрация                               |
| `/subscribe`       | Создать подписку на поиск                 |
| `/list`            | Показать свои подписки                    |
| `/unsubscribe <id>`| Удалить подписку                          |
| `/stop`            | Удалить пользователя и все его данные     |
